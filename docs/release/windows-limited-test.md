# VoxFlow Windows 受限测试版

这是面向有限测试用户的未签名 Windows Release 压缩包，不是正式安装程序。

## 使用方式

1. 校验压缩包随附的 SHA-256。
2. 将压缩包完整解压到本机目录。
3. 运行 `voxflow.exe`；不要只复制可执行文件，旁边的 DLL、插件和 `data` 目录都是运行所需内容。

压缩包已包含应用本地部署所需的 Microsoft Visual C++ 运行库文件，无需预先安装 Flutter SDK、Visual Studio 或 VC++ Redistributable。

Windows SmartScreen 可能提示文件来自未知发布者，这是当前受限测试版已接受的限制。只应从 `glosc-ai` 指定渠道获取压缩包，并在校验值一致后运行。

如果设备的组织策略或 Windows 应用程序控制策略直接阻止未签名程序运行，应停止测试并联系发布维护者。不要关闭或绕过系统安全策略；SmartScreen 可确认警告与策略硬拦截不是同一种情况。

首次启动会显示数据与隐私说明。API Key 使用 Windows 当前用户级 DPAPI 加密保存，不会写入普通应用设置或诊断日志。文本和音频会发送到用户配置的 API 服务商；历史文本、受管音频和脱敏日志保存在本机。设置页的“清空全部数据”可恢复初装状态，但不会删除用户原始导入或另存文件。

## 冒烟范围

- 启动、首次数据与隐私说明和设置持久化。
- 模型获取与连接测试。
- STT 录音、暂停、继续、文件转录及 TXT/SRT 导出。
- TTS 生成、播放、暂停、拖动、音量和另存。
- 历史搜索、复制、重播、删除及重启持久化。
- 日志查看与导出，确认不包含 API Key、认证头或输入正文。
