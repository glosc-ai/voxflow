# VoxFlow 首个上线版本边界

本文基于 2026-07-27 的现有实现、项目文档与逐项确认结果，约束首个上线版本的范围。首个上线版本是面向有限测试用户的 Windows 与 Android MVP，不是公开商店正式版。

## 1. 已经完成且不应推翻的部分

- Windows/Android Flutter 工程、Material 3 响应式导航、Feature-First 目录和 Riverpod 全局状态管理。
- 设置与网络：API Root、API Key、STT/TTS 模型保存，模型目录获取，连接测试，Dio 认证与错误映射。
- STT：倒计时录音、暂停与继续、文件导入、格式和 25 MB 限制、转录、全文编辑及 TXT/SRT 导出。
- TTS：文本、模型、音色和语速校验，MP3 生成、播放控制、拖动、音量与另存。
- 历史记录：Windows FFI/Android SQLite、本地倒序搜索、复制、重播和安全删除受管音频。
- 脱敏 JSONL 日志、日志轮转、查看与导出，以及可重复运行的快速诊断脚本。
- OpenAI 六种标准音色与火山引擎 Seed-TTS 2.0 主表的 93 个常规 Speaker ID；`zh_female_cancan_uranus_bigtts` 保持为已验证的默认音色。

这些能力构成完成基线。首个上线版本只允许补齐发布缺口和修复缺陷，不替换现有架构、技术栈或核心工作流。

## 2. 尚未完成的功能与工作

- Android Release 已配置为缺少正式签名输入即失败，跨平台 GitHub Actions 发布工作流也已实现；仍需由组织配置受保护环境与 Secrets，并取得一次成功正式运行的证据。
- `glosc-ai` 组织必须持续持有唯一 Release keystore，并通过组织级 Secrets 完成签名构建；密钥材料不得进入仓库。
- Android 尚缺至少一台真机上的完整核心流程验收。
- Windows 最终压缩包尚需在不含 Flutter 开发环境的全新沙盒中完成成品验收。
- 尚缺用户可见的数据与隐私说明，需在用户提供 API Key、文本或音频前说明本地保存、外发、日志和删除行为。
- 尚缺“设置状态变化不得中断录音、合成或播放”的针对性回归测试；若测试能复现状态丢失，必须修复。

首版没有其他必须新增的终端用户功能。

## 3. 当前已知缺陷、风险与限制

### 已确认的发布阻断项

- 尚未取得组织受保护工作流生成并验证证书的 Android 候选 APK，不能仅凭本地测试签名产物宣告可升级发布链路通过。
- 双平台成品验收和数据与隐私说明尚未完成。

### 待验证的代码风险

- `dioClientProvider` 监听整个 `settingsProvider`，STT/TTS 服务和状态又依赖该网络 Provider。设置页的忙碌状态、消息或模型目录变化可能级联重建录音、合成或播放器状态。该问题是静态审查发现的风险，尚未确认为可复现缺陷。

### 已接受的受限测试版限制

- API Key 已改由 Windows 当前用户级 DPAPI 或 Android Keystore 加密保存；普通 `SharedPreferences` 与日志不保存密钥。
- Windows 以未签名 Release 压缩包分发，允许出现已提前说明的 SmartScreen 警告。
- Seed TTS 首版承诺内置 93 个官方主表常规 Speaker ID；不承诺代理服务商已为 ICL 或独立多语种表逐项开通资源。
- 历史记录没有分页或虚拟滚动，只适用于受控的测试数据规模。

### 非当前阻断项

- `record_android` 的 Kotlin Gradle Plugin 警告影响未来 Flutter 工具链兼容性，当前构建仍成功。
- Windows 构建环境可能需要下载或缓存 NuGet；最终沙盒成品验收将验证分发包是否真正不依赖开发工具链。
- 本机透明代理 Fake-IP 引发的间歇性 Dart TLS 握手失败属于测试网络环境风险，不能直接归因于 VoxFlow。

当前快速反馈循环未复现核心功能失败：格式检查、静态分析和 35 项自动测试全部通过。

## 4. 上线必须满足的条件

- [ ] Android 使用组织持有的唯一 Release keystore，由 GitHub Actions 组织级 Secrets 注入并成功生成可升级的签名构建。
- [ ] 格式检查、静态分析和现有自动测试全部通过。
- [ ] 增加设置状态隔离回归测试；若能复现核心流程中断，修复后重新通过全部测试。
- [ ] Android 在至少一台真机上完成安装、权限、录音暂停与继续、文件转录、TXT/SRT 导出、TTS 生成与播放、历史操作及重启持久化冒烟测试。
- [ ] Windows 最终 Release 压缩包在全新沙盒中完成启动、设置保存、模型获取、STT、TTS、历史记录、日志导出及重启持久化冒烟测试。
- [ ] 在用户提交敏感数据前提供数据与隐私说明，并明确平台安全存储、数据外发和本地删除边界。
- [ ] 日志与错误信息继续通过现有脱敏测试，任何验收日志不得泄露 API Key、认证头、输入文本或请求正文。
- [ ] 所有上线阻断项关闭，且没有仍可复现的核心流程失败。

## 5. 可以推迟到后续版本的内容

- Windows 安装器、Windows 代码签名、自动更新与回滚。
- 公开商店上架材料及面向公开发布的完整法律文档。
- 火山 ICL、独立多语种表、S2S、Seed-TTS 1.0 音色，动态音色目录和未验证的服务商专属参数。
- 历史记录分页、虚拟滚动和大数据量性能优化。
- 补齐所有 STT/TTS/历史页面边界状态的 Widget 测试和 Android 平台集成自动化测试。
- 在升级 Flutter 工具链时处理 `record_android` 的未来兼容性警告。

延期项不得阻塞受限测试版，但在进入公开发布版规划时必须重新评估。
