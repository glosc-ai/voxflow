## 字栈
- **Display / Body：** `-apple-system, "Segoe UI", "Microsoft YaHei UI", "PingFang SC", "Noto Sans SC", system-ui, sans-serif`（工具型数据密集界面，单一家族；标题靠字重 600–650 + 负字距区分层级）
- **Mono（计时器 / 时间戳 / 数值 / 快捷键）：** `ui-monospace, "Cascadia Code", "JetBrains Mono", Consolas, monospace`，数值一律 `tabular-nums`

## 形状 / 深度
- 圆角刻度：`8px`（标签/徽章）· `12–14px`（输入/按钮/小卡）· `18–20px`（标准卡/对话框）· `24–32px`（录音面板/播放条）
- 深度 = 超软浅阴影 + 1px 边框，禁高投影：`0 4px 16px rgb(15 23 42 / 0.04)`；悬浮壳（导航栏/播放器）可升至 `0 8px 32px rgb(15 23 42 / 0.08)` + `backdrop-filter: blur(10px)`

## 姿态规则（observed）
1. **Shell 悬浮，不贴边。** Windows 左侧 240px NavigationRail，四周留白 16px；顶部放 Logo + API 状态绿光点（带 glow 脉冲）。不用贴边 AppBar。
2. **层级靠留白与边框，不靠投影堆叠。** 卡片永远是 `surface + 1px border + 软阴影`；内容区间用 hairline 分隔，不砌盒子墙。
3. **主色是稀缺资源。** 蓝紫只给：当前导航态、主 CTA、选中态。绿/红只做状态语义，绝不装饰。
4. **数值永远等宽。** 计时器、时长、时间戳、字数统计全部 mono + tabular-nums，右对齐。
5. **一切状态切换 200ms。** hover、录音展开、主题切换、播放器滑入，统一 `0.2s ease`。

## 精修增补（2026-08-03 · 创意总监轮 · 边界：允许突破）

6. **空状态即预览。** 结果容器的 idle 态不放孤立文案，放目标内容的骨架样例（示例时间戳 + 灰条，opacity 50%）——用户在操作前就理解产出形态。
7. **hover 三重反馈。** 主操作 hover = 色彩加深 + 位移 -1px + 阴影扩张，三者同现；按下（:active）归零，按压反馈 ≤ 100ms。
8. **入场曲线一族。** 视图 / 面板进入统一 `cubic-bezier(.2, .8, .2, 1)`（240–320ms）；小状态切换仍 200ms ease；禁止线性 ease 入场。
9. **主题切换全表面同步。** 200ms 过渡覆盖所有 surface / border / color / shadow——禁止"画布变了卡片没变"的撕裂感。
10. **桌面级滚动条。** 内容区 8px 细条、muted 28% 半透明、轨道全透明；禁止原生粗滚动条入镜。
11. **深链状态。** 视图可通过 `#theme=&view=&player=&rec=` 定位与分享——同时作为设计评审与回归截图的驱动接口。

## 第二轮增补（2026-08-03 · 平台真实性与产品完整度）

12. **窗口层真实性。** 面向 Windows 的原型必须有悬浮玻璃标题栏（状态点 + 面包屑 + 版本 + 窗口控制）；关闭按钮 hover = danger 填充（平台惯例，属状态语义预算，不占品牌 accent 配额）。
13. **设置即产品。** 设置是一级导航而非占位 Toast：外观三态（含跟随系统 + `prefers-color-scheme` 监听）、引擎选择跨视图实时同步、快捷键表、本地数据真清除。任何"下一版开放"式占位都违反无死空间原则。
14. **动效伦理。** `prefers-reduced-motion: reduce` 下所有动画/过渡降为即时——录音波纹、脉冲、滑入全部让位。
15. **控件自绘，禁原生外观。** 下拉、输入等表单控件一律按令牌自绘（surface 卡 + 1px border + 软阴影 + accent 选中态 + mono 文本）；原生 `<select>` 弹层不进产品界面。密钥类输入默认掩码，显隐切换在控件内完成。
